## 실제 활동 내용
- 비행기 피하기 게임(파이썬)

| 항목 | 내용 |
| --- | --- |
| 시기 | 2026년 1학기 |
| 상태 | 완료 |
| 유형 | 팀 프로젝트 (파이썬 스터디 최종 결과물) |
| 내 담당 | 아이템 파트 (팀원 1명과 함께 담당) |
| 사용 도구 | Python |

## 목적
- 파이썬 스터디의 마지막 과정으로, 팀원들과 협의해 게임을 개발하기로 했습니다. 스터디에서 배운 파이썬을 실제로 동작하는 하나의 게임으로 만들어 보는 것이 목표였습니다.

## 프로젝트 내 역할
- 팀 프로젝트 내 아이템 파트를 팀원 1명과 함께 맡았습니다.
- 아이템을 만들고, 아이템이 맵의 무작위 위치에 생성되도록 하고, 아이템의 제한 시간을 조정했습니다.
- 코드를 만들 때 AI를 활용했으며, 오류를 확인하거나 모르는 부분이 있을 때에만 활용했습니다.

## 프로젝트 내 코드 분석
`ITEMS`에는 아이템 종류마다 [색상, 효과 지속 시간(초), 이름]을 정의했습니다. `ITEM_LIVE_TIME`은 맵에 나타난 아이템 상자가 사라지기까지의 제한 시간입니다.

```python
ITEM_LIVE_TIME = 5.0  # 맵의 아이템 상자가 유지되는 시간(초)

ITEMS = {
    "invincible":  ["#1e90ff", 5,  "무적"],
    "shield":      ["#ffd700", 10, "방어막"],
    "slow_bullet": ["#dc3232", 5,  "총알감속"],
    "big_plane":   ["#ff6b6b", 10, "대형화"],
    "fast_bullet": ["#ff4500", 5,  "총알가속"],
    "extra_life":  ["#2ecc71", 0,  "목숨+1"],
}
```

## 코드 작성 과정
1. 아이템 효과를 먼저 만들었습니다.
2. 각 아이템의 제한 시간을 조정했습니다.
3. 아이템이 맵의 무작위 위치에 나타나도록 만들었습니다.

아이템이 맵 전체의 무작위 위치에 생기도록 한 이유는, 플레이어가 상하좌우로 자유롭게 움직일 수 있고 총알은 위에서 아래로 떨어지기 때문입니다.
